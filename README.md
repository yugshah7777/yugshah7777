## 🌌 What I Build

<br/>

### 🤖 Agentic AI — *Systems that think for themselves*

> I don't just call APIs. I build **orchestrated multi-agent pipelines** that monitor, reason, plan, and act — without a human in the loop.

My **[Deception Defense System](https://github.com/yugshah7777)** is a LangGraph-orchestrated security agent that ingests live process, file, and network telemetry — then autonomously classifies attack stages, infers attacker intent, and deploys adaptive honeypots before the attacker realizes they've been deceived.

My **[RosterIQ](https://github.com/yugshah7777)** is an AI analytics command center for healthcare roster pipelines. It routes natural-language questions through specialist agents — pipeline diagnostics, quality audits, market health, root-cause chaining — and generates explainable answers with persistent investigation memory.

`LangGraph` · `CrewAI` · `OpenAI SDK` · `Python` · `DuckDB` · `Gradio`

---

### ⛓️ Blockchain & Web3 — *Building where trust is code, not promise*

> I build on **Internet Computer (ICP)** — from smart contracts to full dApps — because I believe decentralized infra should power real products, not just whitepapers.

I've shipped **dBank** (a decentralized banking dApp), **dKeeper** (on-chain note storage), my own **YS7 token** on ICP, and **NFT collections** using Motoko canisters. In **[TattleTent](https://github.com/yugshah7777/TattleTent)**, ICP canisters anchor every complaint lifecycle event as an immutable audit trail — citizens can independently verify their complaints; no admin can tamper with history.

`ICP` · `Motoko` · `Canisters` · `Web3.js`

---

### 🌐 Full Stack — *Products people actually use*

> Clean UIs, solid backends, real data — I build end-to-end, from database schema to the last pixel.

**[TattleTent](https://github.com/yugshah7777/TattleTent)** — civic tech with role-based portals, JWT + Google OAuth, geospatial heatmaps, SLA auto-escalation, and real-time notifications.  
**[Edvora](https://github.com/TeamFelero/Edvora_Hack36)** — college discovery with score-to-college matching, real student reviews, GeoAPI integration, real-time chat via Socket.io, and PayPal gateway. Built with team Felero at Hack36.  
**[La MenteE](https://github.com/yugshah7777/DevJam_LaMenteE)** — cross-institute mentorship network that bridges the student guidance gap. DevJam 2nd Runner-Up.

`React` · `Node.js` · `Express` · `PostgreSQL` · `MongoDB` · `Tailwind` · `Socket.io`
